Module 2: Basic Math and Technical Skills

This module strengthens students' foundational competencies in mathematics and analytical thinking, while also covering essential technical skills such as word processing, data analysis, graphical presentation, and techniques for experimentation and data interpretation.

Duration: Four Weeks (Weeks 5-9)

Module Topics: Essential Technical Skills and Analytical Foundations for Engineering Technology

  1. Mathematical Foundations and Analytical Thinking

    • Fundamental mathematical skills for engineering technology
    • Analytical thinking, problem-solving, and logical reasoning
    • Introduction to engineering data collection, interpretation, and analysis

  2. Word Processing for Technical Documentation

    • Creating and formatting professional laboratory reports and research papers using Microsoft Word
    • Organizing technical information, tables, figures, and references
    • Applying AI-assisted writing tools responsibly to improve clarity, grammar, and technical communication

  3. Creating Technical Presentations with Microsoft PowerPoint

    • Designing professional and visually engaging technical presentations
    • Presenting engineering concepts, experimental results, charts, and graphical information
    • Integrating multimedia and AI-assisted presentation tools to communicate technical information effectively

  4. Spreadsheet Applications for Engineering Data Analysis

    • Understanding spreadsheet organization, formulas, and functions in Microsoft Excel
    • Performing calculations and analyzing engineering data
    • Creating charts and graphs to visualize and communicate experimental results
    • Using AI-assisted tools to support data analysis while verifying accuracy and interpreting results critically

  5. Technical Skills Integration and Project Development

    • Applying word processing, presentation, and spreadsheet skills to engineering technology problems
    • Integrating mathematical analysis, data visualization, and technical communication
    • Developing and presenting a technical project using appropriate digital tools
    • Evaluating the accuracy, quality, and professional presentation of technical work
